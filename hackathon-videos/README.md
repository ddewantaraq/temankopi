## How to film (you)

1. **Intro** — Camera on you; teleprompter on a second screen.
2. **Demo** — Start with 2-sentence problem→solution VO, then screen-record the app (airplane mode + analyze + history + fail-safe) with the short demo VO. Whole clip ≤60s.
3. **Tech** — Screen-record `tech-slide.html` and/or `sequence-flow.html` (open sequence page online once for Mermaid CDN) while reading the tech script from the teleprompter.
